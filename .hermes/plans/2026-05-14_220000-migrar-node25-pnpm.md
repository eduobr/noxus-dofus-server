# Plan: Migrar Noxus a Node 25 + pnpm

**Fecha**: 2026-05-14
**Objetivo**: Ejecutar el emulador Noxus en Node 25.3.0 con pnpm, eliminando
Babel 6 y actualizando dependencias de 2016.

---

## Diagnóstico inicial

| Componente | Estado actual | Objetivo | Brecha |
|-----------|---------------|----------|--------|
| Node.js | v8.17.0 (2017) | v25.3.0 | Breaking changes: ES modules, Buffer, crypto |
| Package manager | npm 6.13.4 | pnpm | Instalación de pnpm |
| Babel | 6.18 (transpila ES6→ES5) | Eliminar | Node 25 soporta ES6+ nativo |
| MongoDB driver | mongodb 2.2.11 | mongodb 6.x | API completamente diferente |
| mongodb-autoincrement | ^1.0.1 | Eliminar | Usar contador manual en MongoDB |
| arraybuffer-to-buffer | 0.0.4 | Eliminar | Buffer.from() nativo |
| base64-js | ^1.2.0 | Evaluar | Buffer.toString('base64') nativo |
| colors | ^1.1.2 | chalk 5.x | API más moderna |
| node-dijkstra | ^2.3.0 | Mantener | Probablemente compatible |

### Fase 4: Convertir imports ES6 → require() CommonJS

**Objetivo**: Eliminar Babel. Los archivos `.js` en `src/` usan `import`/`export`
(ES6). Node 25 en modo CommonJS (`"type": "commonjs"`) no lo soporta.

Estrategia: convertir TODOS los `import`/`export` a `require`/`module.exports`.

**Script automatizado** (ejecutar desde la raíz):

```bash
# Para cada archivo .js en src/
# Patrón: import X from "Y" → const X = require("Y")
# Patrón: import * as X from "Y" → const X = require("Y")
# Patrón: import { X } from "Y" → const { X } = require("Y")
# Patrón: export default class X → module.exports = X
# Patrón: export class X → exports.X = X
# Patrón: export { X } → exports.X = X
```

Hay ~80 archivos. La conversión es mecánica:

| ES6 | CommonJS |
|-----|----------|
| `import X from "./y"` | `const X = require("./y")` |
| `import * as X from "./y"` | `const X = require("./y")` |
| `export default class X {}` | `class X {} ... module.exports = X` |
| `export class X {}` | `class X {} ... exports.X = X` |
| `import { X } from "./y"` | `const { X } = require("./y")` |

Archivos especiales (pre-ES6, no usan import/export):
- `src/io/bytearray.js` — ya es CommonJS, solo necesita `module.exports = ByteArrayBase`
- `src/io/custom_data_wrapper.js` — ya es CommonJS, solo necesita exports explícitos
- `src/enums/*.js` — usan `module.exports = {...}`, ya compatibles

**Riesgo**: Algunos imports usan default + named mezclados. Puede requerir
ajustes manuales en ~5-10 archivos.

### Fase 5: Migrar DBManager a mongodb 6.x

**Objetivo**: Reemplazar las 43 operaciones de MongoDB con la API moderna.

La API de mongodb 6.x usa Promises en lugar de callbacks:

| Antes (2.2.x) | Después (6.x) |
|---|---|
| `MongoClient.connect(url, cb)` | `const client = await MongoClient.connect(url)` |
| `collection.find(q).toArray(cb)` | `await collection.find(q).toArray()` |
| `collection.findOne(q, cb)` | `await collection.findOne(q)` |
| `collection.insertOne(d, cb)` | `await collection.insertOne(d)` |
| `collection.update(q, u, cb)` | `await collection.updateOne(q, { $set: u })` |
| `collection.remove(q)` | `await collection.deleteOne(q)` |
| `autoIncrement.getNextSequence(db, name, cb)` | `await db.collection('counters').findOneAndUpdate(...)` |

**Cambios en `dbmanager.js`**:

1. Conexión: `start()` se vuelve async
2. Todas las funciones cambian de `(params, callback)` a `async (params)`
3. `mongodb-autoincrement` se reemplaza por un contador en colección `counters`

**Ejemplo de migración** (`findAccount`):

```js
// Antes
static findAccount(accountName, callback) {
    var collection = DBManager.db.collection('accounts');
    collection.find({ username: accountName }).toArray(function(err, docs) {
        var account = docs.length > 0 ? new Account(docs[0]) : null;
        callback(account);
    });
}

// Después
static async findAccount(accountName) {
    const collection = DBManager.db.collection('accounts');
    const docs = await collection.find({ username: accountName }).toArray();
    return docs.length > 0 ? new Account(docs[0]) : null;
}
```

**Reimplementación de autoincrement**:

```js
static async getNextSequence(name) {
    const result = await DBManager.db.collection('counters').findOneAndUpdate(
        { _id: name },
        { $inc: { seq: 1 } },
        { upsert: true, returnDocument: 'after' }
    );
    return result.seq;
}
```

**Riesgo**: Las funciones que llaman a DBManager usan callbacks. Hay que
cambiarlas a async/await también. Esto propaga el cambio a:
- `datacenter.js` (loaders) → async
- `handlers/*.js` (varios handlers llaman a DBManager) → async
- `app.js` (arranque) → async

Estimación: ~100-150 líneas modificadas en total.

### Fase 7: Adaptar `app.js` y `datacenter.js` a async/await

**Objetivo**: El arranque del servidor usa callbacks anidados. Convertir a
async/await para legibilidad y compatibilidad con DBManager async.

```js
// Antes (app.js)
ConfigManager.load(function() {
    DBManager.start(function() {
        Datacenter.load(function() {
            AuthServer.start(...);
            WorldServer.start(...);
        });
    });
});

// Después
await ConfigManager.load();
await DBManager.start();
await Datacenter.load();
AuthServer.start(...);
WorldServer.start(...);
```

**Riesgo**: Medio. Afecta al flujo de arranque. Si falla una carga, el
servidor no inicia. Hay que mantener el orden correcto.

## Riesgos y plan B

| Riesgo | Probabilidad | Mitigación |
|--------|-------------|------------|
| mongodb 6.x API incompatible con MongoDB 3.6 | Alta | Bajar mongodb a 4.x (compatible con Mongo 3.6). O usar Mongo 7 en Docker. |
| node-dijkstra no compila en Node 25 | Media | Reimplementar pathfinding con algoritmo propio o buscar fork |
| Conversión import→require rompe dependencias circulares | Media | Detectarlas y romper con require() lazy |
| Handlers async rompen el processor sincrónico | Baja | Processor.js ya es sincrónico; los handlers no devuelven Promises |
| chalk API incompatible con uso de colors | Baja | Adaptar manualmente (~10 líneas) |
| zlib api cambió en Node 25 | Baja | zlib es estable desde Node 0.x |

El proyecto se considera migrado cuando:

5. No existe carpeta `dist/` ni archivo `.babelrc`
